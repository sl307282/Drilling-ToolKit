# Russian (Русский) Oil & Gas Drilling Terminology Glossary (`glossary-ru.md`)

This glossary establishes the standard Russian terminology used across the **Drilling Toolkit** application. Every term is selected based on standard professional drilling engineering practice and industry nomenclature rather than literal machine translation.

---

## 2. Tubulars & Casing Strings
| English Term | Chosen Russian Term | Context / Notes |
| :--- | :--- | :--- |
| **Tubular / Tubulars** | **Трубы / Трубные элементы** | Oil country tubular goods (OCTG) |
| **Casing** | **Обсадная колонна** | Steel casing string protecting borehole |
| **Conductor / Conductor Pipe** | **Направляющая колонна (кондуктор)** | 30" to 36" large structural casing |
| **Surface Casing** | **Кондукторная колонна** | 20" shallow groundwater barrier casing |
| **Intermediate Casing** | **Промежуточная обсадная колонна** | 13-3/8" / 9-5/8" casing isolating unstable formations |
| **Production Casing** | **Эксплуатационная колонна** | Casing isolating target hydrocarbon reservoir |
| **Liner** | **Хвостовик (лайнер)** | Casing string suspended from previous shoe without extending to surface |
| **Casing Shoe** | **Башмак обсадной колонны** | Reinforced lower guide terminal of casing string |
| **Shoe Track** | **Башмачный патрубок (зумпф)** | Internal casing section between float collar and shoe |
| **Float Collar** | **Обратный клапан (муфта со встроенным клапаном)** | Check-valve casing coupling retaining wiper plugs |
| **Drill Pipe (DP)** | **Бурильная труба (СБТ)** | Standard seamless drill pipe conveying rotary torque and fluid |
| **Heavy Weight Drill Pipe (HWDP)** | **Утяжеленная бурильная труба (УБТ / толстостенная)** | Thick-walled intermediate drillstring transition section |
| **Drill Collar (DC)** | **Утяжеленная бурильная труба (УБТ)** | Heavy thick-walled collars providing weight on bit (WOB) |
| **Open Hole** | **Открытый ствол скважины** | Uncased rock borehole section below casing shoe |
| **Burst Pressure / Rating** | **Сопротивление внутреннему давлению (давление разрыва)** | API internal pressure yield capability |
| **Collapse Pressure / Rating** | **Сопротивление внешнему давлению (давление смятия)** | API external pressure crushing resistance |

## 3. Well Cementing
| English Term | Chosen Russian Term | Context / Notes |
| :--- | :--- | :--- |
| **Cementing** | **Цементирование скважины** | Well casing cementing operation |
| **Cement Job Planner** | **Планировщик цементирования** | Subsea / surface casing cement design module |
| **Cement Slurry** | **Цементный раствор** | Hydraulic cement mixed with water and chemical additives |
| **Lead Slurry** | **Головной (облегченный) цементный раствор** | Low density filler cement slurry placed high in annulus |
| **Tail Slurry** | **Хвостовой (тяжелый) цементный раствор** | High density high compressive strength cement slurry across shoe |
| **Spacer** | **Буферная жидкость (спейсер)** | Weighted rheologically tuned fluid separating mud and cement |
| **Displacement Fluid** | **Продавочная жидкость** | Drilling mud or brine pumped behind plugs to displace slurry into annulus |
| **Annular Rise** | **Высота подъема в затрубье** | Vertical height of fluid column in annulus |
| **Top of Cement (TOC)** | **Верхняя граница цемента (TOC)** | Measured depth or TVD of uppermost annular cement column |

## 4. Fluids, Pressures & Hydraulics
| English Term | Chosen Russian Term | Context / Notes |
| :--- | :--- | :--- |
| **Mud Weight (MW)** | **Плотность бурового раствора (MW)** | Drilling fluid specific gravity / density (ppg, SG, kg/m³) |
| **Equivalent Circulating Density (ECD)** | **Эквивалентная циркуляционная плотность (ECD)** | Static mud density plus annular hydraulic pressure loss |
| **Hydrostatic Pressure** | **Гидростатическое давление** | Static pressure exerted by column of liquid (psi = 0.052 * MW * TVD) |
| **Shut-In Drill Pipe Pressure (SIDPP)** | **Давление в бурильных трубах при закрытом устье (SIDPP)** | Gauge pressure on drillpipe after shutting in well on kick |
| **Shut-In Casing Pressure (SICP)** | **Давление в затрубье при закрытом устье (SICP)** | Gauge pressure on casing annulus after shutting in well on kick |
| **Kill Mud Weight (KMW)** | **Плотность раствора глушения (KMW)** | Calculated fluid density to balance formation pore pressure |
| **Leak Off Test (LOT)** | **Испытание на гидроразрыв пласта (LOT)** | Formation fracture pressure test immediately below shoe |

## 6. Well Control & Stuck Pipe
| English Term | Chosen Russian Term | Context / Notes |
| :--- | :--- | :--- |
| **Well Control** | **Контроль скважины и глушение (ГНВП)** | Prevention and mitigation of formation influxes |
| **Kill Sheet** | **Лист глушения скважины (Kill Sheet)** | Worksheet computing pressures and volumes to kill well kick |
| **Kick** | **Проявление пласта (ГНВП / приток)** | Unplanned influx of formation gas/oil/water into wellbore |
| **Blowout** | **Открытый фонтан (выброс)** | Uncontrolled surface release of wellbore fluids |
| **Differential Sticking** | **Дифференциальный прихват** | Pipe stuck against permeable mudcake due to overbalanced hydrostatic pressure |
| **Mechanical Sticking** | **Механический прихват** | Pipe stuck in keyseat or packed cuttings bridge |
