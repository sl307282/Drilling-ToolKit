# French (Français) Oil & Gas Drilling Terminology Glossary (`glossary-fr.md`)

This glossary establishes the standard French terminology used across the **Drilling Toolkit** application. Every term is selected based on standard professional drilling engineering practice and industry nomenclature rather than literal machine translation.

---

## 1. General Drilling & Well Equipment
| English Term | Chosen French Term | Context / Notes |
| :--- | :--- | :--- |
| **Drilling Toolkit** | **Boîte à outils de forage** | App name / Professional brand name |
| **Drilling** | **Forage** | Core drilling process |
| **Wellbore** | **Puits / Trou de forage** | The drilled borehole path |
| **Wellhead** | **Tête de puits** | Surface / subsea well termination |
| **Subsea Wellhead** | **Tête de puits sous-marine** | Offshore seabed wellhead system |
| **Surface Wellhead** | **Tête de puits de surface** | Land or platform wellhead |
| **Drilling Rig** | **Appareil de forage (Rig)** | Complete drilling rig package |
| **Land Rig** | **Appareil de forage terrestre** | Onshore rig |
| **Jack-up Rig** | **Plateforme auto-élévatrice (Jack-up)** | Shallow water bottom-supported rig |
| **Floater / Semi-submersible** | **Appareil flottant / Semi-submersible** | Deepwater floating drilling vessel |
| **BOP (Blowout Preventer)** | **Bloc obturateur de puits (BOP)** | Well control pressure barrier |
| **Surface Stack** | **Ensemble d'obturateurs de surface** | Surface BOP arrangement |
| **Subsea Stack** | **Ensemble d'obturateurs sous-marins** | Seabed BOP arrangement |
| **Choke Line** | **Ligne de duse (Choke line)** | High pressure well control choke conduit |

## 2. Tubulars & Casing Strings
| English Term | Chosen French Term | Context / Notes |
| :--- | :--- | :--- |
| **Tubular / Tubulars** | **Tubulaires** | Oil country tubular goods (OCTG) |
| **Casing** | **Colonne de tubage (Casing)** | Steel casing string protecting borehole |
| **Conductor / Conductor Pipe** | **Tube conducteur (Conductor)** | 30" to 36" large structural casing |
| **Surface Casing** | **Tubage de surface** | 20" shallow groundwater barrier casing |
| **Intermediate Casing** | **Tubage intermédiaire** | 13-3/8" / 9-5/8" casing isolating unstable formations |
| **Production Casing** | **Tubage de production** | Casing isolating target hydrocarbon reservoir |
| **Liner** | **Colonne perdue (Liner)** | Casing string suspended from previous shoe without extending to surface |
| **Casing Shoe** | **Sabot de tubage (Shoe)** | Reinforced lower guide terminal of casing string |
| **Shoe Track** | **Espace sabot-collier (Shoe track)** | Internal casing section between float collar and shoe |
| **Float Collar** | **Collier à clapet (Float collar)** | Check-valve casing coupling retaining wiper plugs |
| **Drill Pipe (DP)** | **Tige de forage (DP)** | Standard seamless drill pipe conveying rotary torque and fluid |
| **Heavy Weight Drill Pipe (HWDP)** | **Tiges lourdes (HWDP)** | Thick-walled intermediate drillstring transition section |
| **Drill Collar (DC)** | **Masse-tiges (DC)** | Heavy thick-walled collars providing weight on bit (WOB) |
| **Open Hole** | **Trou découvert (Open hole)** | Uncased rock borehole section below casing shoe |
| **Burst Pressure / Rating** | **Pression d'éclatement (Burst)** | API internal pressure yield capability |
| **Collapse Pressure / Rating** | **Pression d'écrasement (Collapse)** | API external pressure crushing resistance |

## 3. Well Cementing
| English Term | Chosen French Term | Context / Notes |
| :--- | :--- | :--- |
| **Cementing** | **Cimentation de puits** | Well casing cementing operation |
| **Cement Job Planner** | **Planificateur de cimentation** | Subsea / surface casing cement design module |
| **Cement Slurry** | **Laitier de ciment (Slurry)** | Hydraulic cement mixed with water and chemical additives |
| **Lead Slurry** | **Laitier de tête / allégé (Lead)** | Low density filler cement slurry placed high in annulus |
| **Tail Slurry** | **Laitier de queue / dense (Tail)** | High density high compressive strength cement slurry across shoe |
| **Spacer** | **Fluide tampon (Spacer)** | Weighted rheologically tuned fluid separating mud and cement |
| **Displacement Fluid** | **Fluide de déplacement** | Drilling mud or brine pumped behind plugs to displace slurry into annulus |
| **Annular Rise** | **Montée dans l'annulaire** | Vertical height of fluid column in annulus |
| **Top of Cement (TOC)** | **Sommet du ciment (TOC)** | Measured depth or TVD of uppermost annular cement column |

## 4. Fluids, Pressures & Hydraulics
| English Term | Chosen French Term | Context / Notes |
| :--- | :--- | :--- |
| **Mud Weight (MW)** | **Densité de la boue (MW)** | Drilling fluid specific gravity / density (ppg, SG, kg/m³) |
| **Equivalent Circulating Density (ECD)** | **Densité équivalente en circulation (ECD)** | Static mud density plus annular hydraulic pressure loss |
| **Hydrostatic Pressure** | **Pression hydrostatique** | Static pressure exerted by column of liquid (psi = 0.052 * MW * TVD) |
| **Shut-In Drill Pipe Pressure (SIDPP)** | **Pression en tiges fermées (SIDPP)** | Gauge pressure on drillpipe after shutting in well on kick |
| **Shut-In Casing Pressure (SICP)** | **Pression en tête d'annulaire fermé (SICP)** | Gauge pressure on casing annulus after shutting in well on kick |
| **Kill Mud Weight (KMW)** | **Densité de boue de neutralisation (KMW)** | Calculated fluid density to balance formation pore pressure |
| **Leak Off Test (LOT)** | **Test de fuite de formation (LOT)** | Formation fracture pressure test immediately below shoe |

## 6. Well Control & Stuck Pipe
| English Term | Chosen French Term | Context / Notes |
| :--- | :--- | :--- |
| **Well Control** | **Contrôle de puits** | Prevention and mitigation of formation influxes |
| **Kill Sheet** | **Feuille de contrôle de venue (Kill sheet)** | Worksheet computing pressures and volumes to kill well kick |
| **Kick** | **Venue de fluide (Kick)** | Unplanned influx of formation gas/oil/water into wellbore |
| **Blowout** | **Éruption incontrôlée (Blowout)** | Uncontrolled surface release of wellbore fluids |
| **Differential Sticking** | **Coincement par pression différentielle** | Pipe stuck against permeable mudcake due to overbalanced hydrostatic pressure |
| **Mechanical Sticking** | **Coincement mécanique** | Pipe stuck in keyseat or packed cuttings bridge |
