# Korean (한국어) Oil & Gas Drilling Terminology Glossary (`glossary-ko.md`)

This glossary establishes the standard Korean terminology used across the **Drilling Toolkit** application. Every term is selected based on standard professional drilling engineering practice and industry nomenclature rather than literal machine translation.

---

## 2. Tubulars & Casing Strings
| English Term | Chosen Korean Term | Context / Notes |
| :--- | :--- | :--- |
| **Tubular / Tubulars** | **튜블러 (관재)** | Oil country tubular goods (OCTG) |
| **Casing** | **케이싱 (보호관)** | Steel casing string protecting borehole |
| **Conductor / Conductor Pipe** | **도관 (컨덕터 파이프)** | 30" to 36" large structural casing |
| **Surface Casing** | **표층 케이싱** | 20" shallow groundwater barrier casing |
| **Intermediate Casing** | **중간 케이싱** | 13-3/8" / 9-5/8" casing isolating unstable formations |
| **Production Casing** | **생산용 케이싱** | Casing isolating target hydrocarbon reservoir |
| **Liner** | **라이너** | Casing string suspended from previous shoe without extending to surface |
| **Casing Shoe** | **케이싱 슈 (하단 가이드)** | Reinforced lower guide terminal of casing string |
| **Shoe Track** | **슈 트랙 (플로트 칼라와 슈 사이)** | Internal casing section between float collar and shoe |
| **Float Collar** | **플로트 칼라 (역류방지 밸브 칼라)** | Check-valve casing coupling retaining wiper plugs |
| **Drill Pipe (DP)** | **드릴 파이프 (시추 파이프)** | Standard seamless drill pipe conveying rotary torque and fluid |
| **Heavy Weight Drill Pipe (HWDP)** | **헤비웨이트 드릴 파이프 (HWDP)** | Thick-walled intermediate drillstring transition section |
| **Drill Collar (DC)** | **드릴 칼라 (중량 시추관)** | Heavy thick-walled collars providing weight on bit (WOB) |
| **Open Hole** | **오픈 홀 (나공 구간)** | Uncased rock borehole section below casing shoe |
| **Burst Pressure / Rating** | **파열 압력 (내압 강도)** | API internal pressure yield capability |
| **Collapse Pressure / Rating** | **압궤 압력 (외압 붕괴 강도)** | API external pressure crushing resistance |

## 3. Well Cementing
| English Term | Chosen Korean Term | Context / Notes |
| :--- | :--- | :--- |
| **Cementing** | **시멘팅 (유정 시멘트 작업)** | Well casing cementing operation |
| **Cement Job Planner** | **시멘팅 작업 플래너** | Subsea / surface casing cement design module |
| **Cement Slurry** | **시멘트 슬러리 (배합액)** | Hydraulic cement mixed with water and chemical additives |
| **Lead Slurry** | **리드 슬러리 (저비중 선행 시멘트)** | Low density filler cement slurry placed high in annulus |
| **Tail Slurry** | **테일 슬러리 (고비중 고강도 후행 시멘트)** | High density high compressive strength cement slurry across shoe |
| **Spacer** | **스페이서 (완충 분리액)** | Weighted rheologically tuned fluid separating mud and cement |
| **Displacement Fluid** | **치환 유체 (밀어내기 액)** | Drilling mud or brine pumped behind plugs to displace slurry into annulus |
| **Annular Rise** | **환상 공간 상승 높이 (애뉴러스 라이즈)** | Vertical height of fluid column in annulus |
| **Top of Cement (TOC)** | **시멘트 최상단 깊이 (TOC)** | Measured depth or TVD of uppermost annular cement column |

## 4. Fluids, Pressures & Hydraulics
| English Term | Chosen Korean Term | Context / Notes |
| :--- | :--- | :--- |
| **Mud Weight (MW)** | **이수 비중 (머드 웨이트 MW)** | Drilling fluid specific gravity / density (ppg, SG, kg/m³) |
| **Equivalent Circulating Density (ECD)** | **등가 순환 밀도 (ECD)** | Static mud density plus annular hydraulic pressure loss |
| **Hydrostatic Pressure** | **정수압 (유체 정압)** | Static pressure exerted by column of liquid (psi = 0.052 * MW * TVD) |
| **Shut-In Drill Pipe Pressure (SIDPP)** | **폐쇄 드릴 파이프 압력 (SIDPP)** | Gauge pressure on drillpipe after shutting in well on kick |
| **Shut-In Casing Pressure (SICP)** | **폐쇄 케이싱 압력 (SICP)** | Gauge pressure on casing annulus after shutting in well on kick |
| **Kill Mud Weight (KMW)** | **킬 머드 비중 (유정 제어 이수 밀도 KMW)** | Calculated fluid density to balance formation pore pressure |
| **Leak Off Test (LOT)** | **누출 시험 (지층 파쇄 압력 시험 LOT)** | Formation fracture pressure test immediately below shoe |

## 6. Well Control & Stuck Pipe
| English Term | Chosen Korean Term | Context / Notes |
| :--- | :--- | :--- |
| **Well Control** | **유정 제어 (웰 컨트롤)** | Prevention and mitigation of formation influxes |
| **Kill Sheet** | **킬 시트 (유정 압력 제어 계산서)** | Worksheet computing pressures and volumes to kill well kick |
| **Kick** | **킥 (지층 유체 침입 현상)** | Unplanned influx of formation gas/oil/water into wellbore |
| **Blowout** | **블로우아웃 (통제 불능 폭발 분출)** | Uncontrolled surface release of wellbore fluids |
| **Differential Sticking** | **차압 점착 파이프 고착 (디퍼렌셜 스티킹)** | Pipe stuck against permeable mudcake due to overbalanced hydrostatic pressure |
| **Mechanical Sticking** | **기계적 파이프 고착 (메커니컬 스티킹)** | Pipe stuck in keyseat or packed cuttings bridge |
