# Hindi (हिन्दी) Oil & Gas Drilling Terminology Glossary (`glossary-hi.md`)

This glossary establishes the standard Hindi terminology used across the **Drilling Toolkit** application. Every term is selected based on standard professional drilling engineering practice and industry nomenclature rather than literal machine translation.

---

| **Casing** | **केसिंग (आवरण नलिका)** | Steel casing string protecting borehole |
| **Conductor / Conductor Pipe** | **कंडक्टर पाइप** | 30" to 36" large structural casing |
| **Surface Casing** | **सरफेस केसिंग** | 20" shallow groundwater barrier casing |
| **Intermediate Casing** | **इंटरमीडिएट केसिंग** | 13-3/8" / 9-5/8" casing isolating unstable formations |
| **Production Casing** | **प्रोडक्शन केसिंग** | Casing isolating target hydrocarbon reservoir |
| **Liner** | **लाइनर** | Casing string suspended from previous shoe without extending to surface |
| **Casing Shoe** | **केसिंग शू** | Reinforced lower guide terminal of casing string |
| **Shoe Track** | **शू ट्रैक** | Internal casing section between float collar and shoe |
| **Float Collar** | **फ्लोट कॉलर** | Check-valve casing coupling retaining wiper plugs |
| **Drill Pipe (DP)** | **ड्रिल पाइप (DP)** | Standard seamless drill pipe conveying rotary torque and fluid |
| **Heavy Weight Drill Pipe (HWDP)** | **हैवी वेट ड्रिल पाइप (HWDP)** | Thick-walled intermediate drillstring transition section |
| **Drill Collar (DC)** | **ड्रिल कॉलर (DC)** | Heavy thick-walled collars providing weight on bit (WOB) |
| **Open Hole** | **ओपन होल** | Uncased rock borehole section below casing shoe |
| **Burst Pressure / Rating** | **बर्स्ट प्रेशर / रेटिंग** | API internal pressure yield capability |
| **Collapse Pressure / Rating** | **कोलैप्स प्रेशर / रेटिंग** | API external pressure crushing resistance |

| **Annular Rise** | **एनुलर राइज (वलयाकार वृद्धि)** | Vertical height of fluid column in annulus |
| **Top of Cement (TOC)** | **टॉप ऑफ सीमेंट (TOC)** | Measured depth or TVD of uppermost annular cement column |

## 4. Fluids, Pressures & Hydraulics
| English Term | Chosen Hindi Term | Context / Notes |
| :--- | :--- | :--- |
| **Mud Weight (MW)** | **मड वेट (MW / घोल घनत्व)** | Drilling fluid specific gravity / density (ppg, SG, kg/m³) |
| **Equivalent Circulating Density (ECD)** | **समतुल्य परिसंचारी घनत्व (ECD)** | Static mud density plus annular hydraulic pressure loss |
| **Hydrostatic Pressure** | **हाइड्रोस्टैटिक दबाव** | Static pressure exerted by column of liquid (psi = 0.052 * MW * TVD) |
| **Shut-In Drill Pipe Pressure (SIDPP)** | **शट-इन ड्रिल पाइप प्रेशर (SIDPP)** | Gauge pressure on drillpipe after shutting in well on kick |
| **Shut-In Casing Pressure (SICP)** | **शट-इन केसिंग प्रेशर (SICP)** | Gauge pressure on casing annulus after shutting in well on kick |
| **Kill Mud Weight (KMW)** | **किल मड वेट (KMW)** | Calculated fluid density to balance formation pore pressure |
| **Leak Off Test (LOT)** | **लीक-ऑफ टेस्ट (LOT)** | Formation fracture pressure test immediately below shoe |

## 6. Well Control & Stuck Pipe
| English Term | Chosen Hindi Term | Context / Notes |
| :--- | :--- | :--- |
| **Well Control** | **वेल कंट्रोल (कूप नियंत्रण)** | Prevention and mitigation of formation influxes |
| **Kill Sheet** | **किल शीट (दबाव नियंत्रण प्रपत्र)** | Worksheet computing pressures and volumes to kill well kick |
| **Kick** | **किक (गैस या तरल अंतर्वाह)** | Unplanned influx of formation gas/oil/water into wellbore |
| **Blowout** | **ब्लोआउट (विस्फोटक रिसाव)** | Uncontrolled surface release of wellbore fluids |
| **Differential Sticking** | **डिफरेंशियल स्टिकिंग** | Pipe stuck against permeable mudcake due to overbalanced hydrostatic pressure |
| **Mechanical Sticking** | **मैकेनिकल स्टिकिंग** | Pipe stuck in keyseat or packed cuttings bridge |
