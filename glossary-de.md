# German (Deutsch) Oil & Gas Drilling Terminology Glossary (`glossary-de.md`)

This glossary establishes the standard German terminology used across the **Drilling Toolkit** application. Every term is selected based on standard professional drilling engineering practice and industry nomenclature rather than literal machine translation.

---

## 2. Tubulars & Casing Strings
| English Term | Chosen German Term | Context / Notes |
| :--- | :--- | :--- |
| **Tubular / Tubulars** | **Rohrkomponenten (Tubulars)** | Oil country tubular goods (OCTG) |
| **Casing** | **Futterrohr / Verrohrung (Casing)** | Steel casing string protecting borehole |
| **Conductor / Conductor Pipe** | **Leitrohr (Conductor)** | 30" to 36" large structural casing |
| **Surface Casing** | **Standrohrtour (Surface Casing)** | 20" shallow groundwater barrier casing |
| **Intermediate Casing** | **Zwischenverrohrung** | 13-3/8" / 9-5/8" casing isolating unstable formations |
| **Production Casing** | **Produktionsverrohrung** | Casing isolating target hydrocarbon reservoir |
| **Liner** | **Liner (Verlorene Rohrtour)** | Casing string suspended from previous shoe without extending to surface |
| **Casing Shoe** | **Bohrschuh / Rohrschuh** | Reinforced lower guide terminal of casing string |
| **Shoe Track** | **Schuhtrack (Strecke Schuh-Ventil)** | Internal casing section between float collar and shoe |
| **Float Collar** | **Rückschlagventil-Muffe (Float Collar)** | Check-valve casing coupling retaining wiper plugs |
| **Drill Pipe (DP)** | **Bohrgestänge (Drill Pipe)** | Standard seamless drill pipe conveying rotary torque and fluid |
| **Heavy Weight Drill Pipe (HWDP)** | **Schwergestänge (HWDP)** | Thick-walled intermediate drillstring transition section |
| **Drill Collar (DC)** | **Schwerstange (Drill Collar)** | Heavy thick-walled collars providing weight on bit (WOB) |
| **Open Hole** | **Offenes Bohrloch (Open Hole)** | Uncased rock borehole section below casing shoe |
| **Burst Pressure / Rating** | **Innendruck-Berstgrenze (Burst)** | API internal pressure yield capability |
| **Collapse Pressure / Rating** | **Außendruck-Kollapsgrenze** | API external pressure crushing resistance |

## 3. Well Cementing
| English Term | Chosen German Term | Context / Notes |
| :--- | :--- | :--- |
| **Cementing** | **Zementation / Bohrlochzementierung** | Well casing cementing operation |
| **Cement Job Planner** | **Zementier-Arbeitsplaner** | Subsea / surface casing cement design module |
| **Cement Slurry** | **Zementsuspension (Slurry)** | Hydraulic cement mixed with water and chemical additives |
| **Lead Slurry** | **Vorlauf-Zementsuspension (Lead)** | Low density filler cement slurry placed high in annulus |
| **Tail Slurry** | **Nachlauf-Zementsuspension (Tail)** | High density high compressive strength cement slurry across shoe |
| **Spacer** | **Abstandshalter-Flüssigkeit (Spacer)** | Weighted rheologically tuned fluid separating mud and cement |
| **Displacement Fluid** | **Verdrängungsflüssigkeit** | Drilling mud or brine pumped behind plugs to displace slurry into annulus |
| **Annular Rise** | **Ringraum-Aufstiegshöhe** | Vertical height of fluid column in annulus |
| **Top of Cement (TOC)** | **Zementobergrenze (TOC)** | Measured depth or TVD of uppermost annular cement column |

## 4. Fluids, Pressures & Hydraulics
| English Term | Chosen German Term | Context / Notes |
| :--- | :--- | :--- |
| **Mud Weight (MW)** | **Spülungsdichte (MW)** | Drilling fluid specific gravity / density (ppg, SG, kg/m³) |
| **Equivalent Circulating Density (ECD)** | **Äquivalente Zirkulationsdichte (ECD)** | Static mud density plus annular hydraulic pressure loss |
| **Hydrostatic Pressure** | **Hydrostatischer Druck** | Static pressure exerted by column of liquid (psi = 0.052 * MW * TVD) |
| **Shut-In Drill Pipe Pressure (SIDPP)** | **Eingeschlossener Bohrgestängedruck (SIDPP)** | Gauge pressure on drillpipe after shutting in well on kick |
| **Shut-In Casing Pressure (SICP)** | **Eingeschlossener Futterrohrdruck (SICP)** | Gauge pressure on casing annulus after shutting in well on kick |
| **Kill Mud Weight (KMW)** | **Tötungsschlammdichte (KMW)** | Calculated fluid density to balance formation pore pressure |
| **Leak Off Test (LOT)** | **Druckaufnahmetest (Leak-Off Test LOT)** | Formation fracture pressure test immediately below shoe |

## 6. Well Control & Stuck Pipe
| English Term | Chosen German Term | Context / Notes |
| :--- | :--- | :--- |
| **Well Control** | **Bohrlochkontrolle (Well Control)** | Prevention and mitigation of formation influxes |
| **Kill Sheet** | **Tötungsarbeitsblatt (Kill Sheet)** | Worksheet computing pressures and volumes to kill well kick |
| **Kick** | **Kick (Formationsfluideinbruch)** | Unplanned influx of formation gas/oil/water into wellbore |
| **Blowout** | **Blowout (Unkontrollierter Ausbruch)** | Uncontrolled surface release of wellbore fluids |
| **Differential Sticking** | **Differenzdruckkleben (Differential Sticking)** | Pipe stuck against permeable mudcake due to overbalanced hydrostatic pressure |
| **Mechanical Sticking** | **Mechanisches Feststecken** | Pipe stuck in keyseat or packed cuttings bridge |
