# Arabic (العربية) Oil & Gas Drilling Terminology Glossary (`glossary-ar.md`)

This glossary establishes the standard Arabic terminology used across the **Drilling Toolkit** application. Every term is selected based on standard professional drilling engineering practice and industry nomenclature rather than literal machine translation.

---

## 2. Tubulars & Casing Strings
| English Term | Chosen Arabic Term | Context / Notes |
| :--- | :--- | :--- |
| **Tubular / Tubulars** | **أنابيب الحفر والتغليف** | Oil country tubular goods (OCTG) |
| **Casing** | **أنابيب التغليف** | Steel casing string protecting borehole |
| **Conductor / Conductor Pipe** | **أنبوب التوجيه (الكوندكتور)** | 30" to 36" large structural casing |
| **Surface Casing** | **أنبوب التغليف السطحي** | 20" shallow groundwater barrier casing |
| **Intermediate Casing** | **أنبوب التغليف الوسيط** | 13-3/8" / 9-5/8" casing isolating unstable formations |
| **Production Casing** | **أنبوب التغليف الإنتاجي** | Casing isolating target hydrocarbon reservoir |
| **Liner** | **بطانة التغليف (اللاينر)** | Casing string suspended from previous shoe without extending to surface |
| **Casing Shoe** | **حذاء أنبوب التغليف** | Reinforced lower guide terminal of casing string |
| **Shoe Track** | **مسار الحذاء (بين الصمام والحذاء)** | Internal casing section between float collar and shoe |
| **Float Collar** | **طوق الصمام الراجع (Float Collar)** | Check-valve casing coupling retaining wiper plugs |
| **Drill Pipe (DP)** | **أنبوب الحفر (DP)** | Standard seamless drill pipe conveying rotary torque and fluid |
| **Heavy Weight Drill Pipe (HWDP)** | **أنابيب الحفر الثقيلة (HWDP)** | Thick-walled intermediate drillstring transition section |
| **Drill Collar (DC)** | **أطواق الحفر الثقيلة (DC)** | Heavy thick-walled collars providing weight on bit (WOB) |
| **Open Hole** | **القطاع المفتوح من البئر** | Uncased rock borehole section below casing shoe |
| **Burst Pressure / Rating** | **ضغط الانفجار الداخلي للأنابيب** | API internal pressure yield capability |
| **Collapse Pressure / Rating** | **مقاومة الانبعاج الخارجي (Collapse)** | API external pressure crushing resistance |

## 3. Well Cementing
| English Term | Chosen Arabic Term | Context / Notes |
| :--- | :--- | :--- |
| **Cementing** | **عمليات تسميت الآبار** | Well casing cementing operation |
| **Cement Job Planner** | **مخطط عمليات التسميت** | Subsea / surface casing cement design module |
| **Cement Slurry** | **ملاط الأسمنت** | Hydraulic cement mixed with water and chemical additives |
| **Lead Slurry** | **ملاط الأسمنت التمهيدي الخفيف (Lead)** | Low density filler cement slurry placed high in annulus |
| **Tail Slurry** | **ملاط الأسمنت النهائي عالي الكثافة (Tail)** | High density high compressive strength cement slurry across shoe |
| **Spacer** | **سائل المباعدة الفاصل (Spacer)** | Weighted rheologically tuned fluid separating mud and cement |
| **Displacement Fluid** | **سائل الإزاحة** | Drilling mud or brine pumped behind plugs to displace slurry into annulus |
| **Annular Rise** | **ارتفاع السائل في الحيز الحلقي** | Vertical height of fluid column in annulus |
| **Top of Cement (TOC)** | **قمة عمود الأسمنت (TOC)** | Measured depth or TVD of uppermost annular cement column |

## 4. Fluids, Pressures & Hydraulics
| English Term | Chosen Arabic Term | Context / Notes |
| :--- | :--- | :--- |
| **Mud Weight (MW)** | **كثافة طين الحفر (MW)** | Drilling fluid specific gravity / density (ppg, SG, kg/m³) |
| **Equivalent Circulating Density (ECD)** | **الكثافة المكافئة أثناء الدوران (ECD)** | Static mud density plus annular hydraulic pressure loss |
| **Hydrostatic Pressure** | **الضغط الهيدروستاتيكي** | Static pressure exerted by column of liquid (psi = 0.052 * MW * TVD) |
| **Shut-In Drill Pipe Pressure (SIDPP)** | **ضغط أنابيب الحفر عند الإغلاق (SIDPP)** | Gauge pressure on drillpipe after shutting in well on kick |
| **Shut-In Casing Pressure (SICP)** | **ضغط أنبوب التغليف عند الإغلاق (SICP)** | Gauge pressure on casing annulus after shutting in well on kick |
| **Kill Mud Weight (KMW)** | **كثافة طين القتل اللازمة (KMW)** | Calculated fluid density to balance formation pore pressure |
| **Leak Off Test (LOT)** | **اختبار تسريب التكوين (LOT)** | Formation fracture pressure test immediately below shoe |

## 6. Well Control & Stuck Pipe
| English Term | Chosen Arabic Term | Context / Notes |
| :--- | :--- | :--- |
| **Well Control** | **التحكم في الآبار وضبط الضغط** | Prevention and mitigation of formation influxes |
| **Kill Sheet** | **ورقة حسابات قتل البئر (Kill Sheet)** | Worksheet computing pressures and volumes to kill well kick |
| **Kick** | **اندفاع مائع التكوين (Kick)** | Unplanned influx of formation gas/oil/water into wellbore |
| **Blowout** | **انفجار البئر غير المنضبط** | Uncontrolled surface release of wellbore fluids |
| **Differential Sticking** | **استعصاء الأنابيب بفرق الضغط** | Pipe stuck against permeable mudcake due to overbalanced hydrostatic pressure |
| **Mechanical Sticking** | **استعصاء ميكانيكي للأنابيب** | Pipe stuck in keyseat or packed cuttings bridge |
