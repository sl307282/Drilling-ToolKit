# Spanish (Español) Oil & Gas Drilling Terminology Glossary (`glossary-es.md`)

This glossary establishes the standard Spanish terminology used across the **Drilling Toolkit** application. Every term is selected based on standard professional drilling engineering practice and industry nomenclature rather than literal machine translation.

---

| :--- | :--- | :--- |

| **Casing** | **Tubería de revestimiento (Casing)** | Steel casing string protecting borehole |

| **Surface Casing** | **Revestimiento superficial** | 20" shallow groundwater barrier casing |

| **Production Casing** | **Revestimiento de producción** | Casing isolating target hydrocarbon reservoir |
| **Liner** | **Tubería corta (Liner)** | Casing string suspended from previous shoe without extending to surface |
| **Casing Shoe** | **Zapata de revestimiento (Shoe)** | Reinforced lower guide terminal of casing string |
| **Shoe Track** | **Tramo de zapata (Shoe Track)** | Internal casing section between float collar and shoe |
| **Float Collar** | **Cuello flotador (Float Collar)** | Check-valve casing coupling retaining wiper plugs |
| **Drill Pipe (DP)** | **Tubería de perforación (DP)** | Standard seamless drill pipe conveying rotary torque and fluid |
| **Heavy Weight Drill Pipe (HWDP)** | **Tubería de perforación pesada (HWDP)** | Thick-walled intermediate drillstring transition section |
| **Drill Collar (DC)** | **Portamechas / Lastrabarrenas (DC)** | Heavy thick-walled collars providing weight on bit (WOB) |
| **Open Hole** | **Hueco abierto / Agujero descubierto** | Uncased rock borehole section below casing shoe |
| **Burst Pressure / Rating** | **Resistencia a la presión interna (Burst)** | API internal pressure yield capability |
| **Collapse Pressure / Rating** | **Resistencia al colapso externo** | API external pressure crushing resistance |

## 3. Well Cementing
| English Term | Chosen Spanish Term | Context / Notes |
| :--- | :--- | :--- |
| **Cementing** | **Cementación de pozos** | Well casing cementing operation |
| **Cement Job Planner** | **Planificador de cementación** | Subsea / surface casing cement design module |
| **Cement Slurry** | **Lechada de cemento** | Hydraulic cement mixed with water and chemical additives |
| **Lead Slurry** | **Lechada de llenado / liviana (Lead)** | Low density filler cement slurry placed high in annulus |
| **Tail Slurry** | **Lechada de cola / pesada (Tail)** | High density high compressive strength cement slurry across shoe |
| **Spacer** | **Espaciador (Spacer)** | Weighted rheologically tuned fluid separating mud and cement |
| **Displacement Fluid** | **Fluido de desplazamiento** | Drilling mud or brine pumped behind plugs to displace slurry into annulus |
| **Annular Rise** | **Ascenso anular / Altura en el anular** | Vertical height of fluid column in annulus |
| **Top of Cement (TOC)** | **Tope del cemento (TOC)** | Measured depth or TVD of uppermost annular cement column |

## 4. Fluids, Pressures & Hydraulics
| English Term | Chosen Spanish Term | Context / Notes |
| :--- | :--- | :--- |
| **Mud Weight (MW)** | **Densidad del lodo (MW)** | Drilling fluid specific gravity / density (ppg, SG, kg/m³) |
| **Equivalent Circulating Density (ECD)** | **Densidad equivalente de circulación (ECD)** | Static mud density plus annular hydraulic pressure loss |
| **Hydrostatic Pressure** | **Presión hidrostática** | Static pressure exerted by column of liquid (psi = 0.052 * MW * TVD) |
| **Shut-In Drill Pipe Pressure (SIDPP)** | **Presión de cierre en tubería de perforación (SIDPP)** | Gauge pressure on drillpipe after shutting in well on kick |
| **Shut-In Casing Pressure (SICP)** | **Presión de cierre en revestimiento (SICP)** | Gauge pressure on casing annulus after shutting in well on kick |
| **Kill Mud Weight (KMW)** | **Densidad del lodo de ahogo (KMW)** | Calculated fluid density to balance formation pore pressure |
| **Leak Off Test (LOT)** | **Prueba de goteo / admisión (LOT)** | Formation fracture pressure test immediately below shoe |

## 6. Well Control & Stuck Pipe
| English Term | Chosen Spanish Term | Context / Notes |
| :--- | :--- | :--- |
| **Well Control** | **Control de pozos** | Prevention and mitigation of formation influxes |
| **Kill Sheet** | **Hoja de cálculo de ahogo (Kill Sheet)** | Worksheet computing pressures and volumes to kill well kick |
| **Kick** | **Amago de reventón / Invasión (Kick)** | Unplanned influx of formation gas/oil/water into wellbore |
| **Blowout** | **Reventón incontrolado (Blowout)** | Uncontrolled surface release of wellbore fluids |
| **Differential Sticking** | **Pegadura por presión diferencial** | Pipe stuck against permeable mudcake due to overbalanced hydrostatic pressure |
| **Mechanical Sticking** | **Pegadura mecánica** | Pipe stuck in keyseat or packed cuttings bridge |
